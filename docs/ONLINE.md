# 在线歌单接入

## 使用

核心仍只需 Python 3.10+。网易云：安装 Node.js 22+，运行 start-netease.cmd（首次按 package-lock 安装），再运行 start.cmd，粘贴标准歌单链接。

QQ 音乐：运行 start-qqmusic.cmd，首次创建独立 .venv 并按 requirements-lock.txt 安装依赖；再在主页面导入 QQ 歌单。已验证环境为 Windows / Python 3.12。辅助窗口需要保持运行。端口：主页面 8848、网易云 8850、QQ 8851，均仅监听本机。安装失败可重新运行，不修改全局 Python 库。

标准链接包括网易云 /playlist?id=123 与 /#/playlist?id=123，QQ /n/ryqq/playlist/123 和 taoge?id=123。暂不展开短链接；在浏览器打开短链接，再复制完整地址。只读取元数据；不下载音频，不登录账号、不写入远端歌单。需要授权的歌单当前采用 CSV 导入，不将私密／失效／限流当作空歌单。

## 完整性

网易云先核对 trackCount 与完整 trackIds，按 100 首分批读详情，按原 ID 列表恢复顺序与重复项，缺歌手保留为空。读完再次核对 ID 列表，变化或缺失即拒绝导入部分结果。

QQ 按 100 首逐页读，核对每页总数、hasmore、重复页面与最终记录数，保留歌曲顺序和页内重复项。读完复核第一页和总数。接口不提供完整快照，因此无法排除总数和第一页不变的中间页同时变更；请对长期可变歌单重试或使用导出 CSV。

读取失败保留上一份匹配结果；完成后进入同一 Matcher，候选仍不计为确认。服务请求仅允许固定本机端口和固定元数据接口，不将用户 URL 当作任意网络地址。
